# The Tired Dark Lord: A 100-Word Villain Monologue

Entry for the [make.fun bounty](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb): a program that writes a 100-word monologue spoken by a fantasy villain who is secretly just very tired.

Vey Marrow, Lord of the Hollow Toll, drowned King Aldous's fleet nine hundred years ago and has been stamping souls ever since — but tonight he is supposed to loose his mire-wyrms on Dawnland, and the Dawnlands sent a form. In triplicate.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

The program is deterministic, standard library only, and needs no network. It asserts the monologue is exactly 100 words and 1–600 characters before writing.
